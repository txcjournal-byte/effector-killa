TrapWin BEND DEMON 2.0.0 - Windows installation (Windows 10/11, 64-bit)
=======================================================================

1. Unzip this file and run "TrapWinBendDemon-2.0.0-Windows-Setup.exe".
   (If Windows SmartScreen appears: "More info" > "Run anyway".)
2. The installer puts the VST3 plugin here:
       C:\Program Files\Common Files\VST3\TrapWin BEND DEMON.vst3
   and optionally the standalone app in C:\Program Files\TrapWin\BEND DEMON.
3. FL Studio: Options > Manage plugins > "Find installed plugins" (rescan),
   then tick TrapWin BEND DEMON (Generators) and add it to a channel.
   Other DAWs: rescan your VST3 folder.
   Updating from 1.0.0: the installer removes the old "BEND DEMON" plugin for you.

Getting started (2.0)
- Add BEND DEMON to a channel. It already has a demo pattern and a built-in sound:
  press play in your DAW (or the PLAY button in the plugin) and you hear slides right away.
- Draw your own lines with the pencil: one line = one note that can slide anywhere.
- Pick a sound at the top (SOUND), or load your own synth. Synths with MPE (Serum 2, Vital,
  Pigments, Phase Plant, Surge XT ...) slide every note on its own; other synths get mono slides
  automatically (set their pitch-bend range to the value in the settings menu, default 48).
- LIVE mode (top bar) = the 1.x behaviour: your piano-roll notes are bent by the gestures.

Uninstall: Windows Settings > Apps > TrapWin BEND DEMON.
