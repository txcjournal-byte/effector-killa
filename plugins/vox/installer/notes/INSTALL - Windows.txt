TrapWin VOX DEMON - Windows install

1. Run TrapWin-VOX-DEMON-Setup.exe and click through the installer.
   (Or copy the folder "TrapWin VOX DEMON.vst3" to C:\Program Files\Common Files\VST3 yourself.)
2. FL Studio: Options > Manage plugins > Find more plugins.
3. Load "TrapWin VOX DEMON" on your vocal track (any mixer insert).
