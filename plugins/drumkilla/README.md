# DRUM KILLA (TrapWin)

Drum damage unit – saturation, clipper and HIT for 808s, kicks, snares, claps, hats, percs and drum buses
(VST3 / AU / Standalone, Windows + macOS). Built on the 808 KILLA engine with a tunable FOCUS frequency
and 42 factory presets sorted by drum type (808, KICK, SNARE, CLAP, HATS, PERC, DRUM BUS).

- Plugin codes (never change): manufacturer `Trpw`, plugin `TwDk`
- `tools/make_drumkilla_logo.py` – replaces the logo in the background art (original in `Resources/source/`)
- CI: `.github/workflows/drumkilla.yml` (branch `plugins`) – tests, pluginval, auval, signed + notarized Mac,
  Windows installer, artifact **SHOP-DRUM-KILLA** with the two shop downloads
