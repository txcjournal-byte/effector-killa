TrapWin WIDE - Windows install

1. Run TrapWin-WIDE-Setup.exe and click through the installer.
   (Or copy the folder "TrapWin WIDE.vst3" to C:\Program Files\Common Files\VST3 yourself.)
2. FL Studio: Options > Manage plugins > Find more plugins.
3. Load "TrapWin WIDE" on your stereo track, bus or master (any mixer insert).
